WISHBONE WRAPPER OF WDT 

HOW TO USE:
1. ENABLE 
2. INSERT RELOAD VALUE
3. WAIT FOR TO OR FEED THIS BY ENABLE = 0;

OFFSET WHEN USING WISHBONE:
timer_REG_OFFSET = 8'h00; //RO, VALUE OF TIMER - COUNT DOWN BY RELOAD VALUE - 1 EACH CLOCK;
load_REG_OFFSET = 8'h04; //RW, RELOAD VALUE
control_REG_OFFSET = 8'h08; //RW, ENABLE WDT, EN = 1 IS WDT IS RUNNING, EM = 0 IS FEEDING THIS WDT, WILL RUN BACK TO RELOAD VALUE
IM_REG_OFFSET = 8'hc; // RW, INTERUPT MASK, WRITE TO IM = 1 WILL ENABLE TO SEND TO IRQ
MIS_REG_OFFSET = 8'h10; // RO, RIS & IM
RIS_REG_OFFSET = 8'h14; //RO, RAW INTERUPT, = WDTTO
IC_REG_OFFSET = 8'h18; // RW, IC = 1 TO CLEAR TO
GCLK_REG_OFFSET = 8'h1c; //RW, CLOCK GATING, GCLK = 1, WDT WILL RUN
